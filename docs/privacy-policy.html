교회학교 암송 수첩 개인정보처리방침

시행일: 2026년 6월 3일 · 최종 개정 2026년 8월 18일

본 앱은 사용자의 개인정보를 외부 서버로 전송하거나 수집하지 않습니다. 모든 데이터는 사용자의 기기 내부에만 저장됩니다.

1. 수집하는 정보

본 앱은 다음 정보를 사용자 기기 내부에만 저장하며, 외부로 전송하지 않습니다.

  • 암송 진행 상태(체크 기록, 진도율, 포인트, 배지, 연속 일수)
  • 북마크한 말씀 목록
  • 사용자가 설정한 알림 시간 및 폰트 크기
  • 사용자가 직접 추가한 메모

위 정보는 모두 기기의 로컬 저장소(LocalStorage, IndexedDB)에 저장되며, 앱을 삭제하면 모두 함께 제거됩니다.

2. 수집하지 않는 정보

  • 이름, 이메일, 전화번호 등 개인 식별 정보
  • 위치 정보
  • 연락처 및 주소록
  • 사용 통계 또는 분석 데이터
  • 광고 식별자

3. 앱이 요청하는 권한

권한용도
인터넷앱 내부 웹뷰 동작에 필요 (외부 서버 통신 없음)
알림사용자가 설정한 시간에 암송 알림 표시 (모든 알림은 기기 내에서 발생)
사진/저장소암송 카드 이미지를 사용자 갤러리에 저장할 때만 사용
마이크 · 음성 인식"완전 암송" 연습에서 암송한 말씀을 음성으로 입력할 때만 사용 (아래 3-1 참고)

3-1. 음성 인식에 대하여

"완전 암송" 연습에서 마이크 버튼을 눌렀을 때만 음성 인식이 동작합니다.

  • 본 앱은 음성을 녹음하여 저장하지 않으며, 개발자의 서버로 전송하지 않습니다.
  • 음성을 텍스트로 바꾸는 처리는 운영체제가 제공하는 음성 인식 기능을 이용합니다. 이 과정에서 음성 데이터가 Apple(iOS) 또는 Google(Android)의 음성 인식 시스템으로 전송되어 처리될 수 있습니다. 해당 처리는 각 사업자의 개인정보처리방침을 따릅니다. (Apple · Google)
  • 변환된 텍스트는 암송 정답을 확인하는 데에만 쓰이며, 확인 후 저장되지 않습니다.
  • 마이크 권한을 허용하지 않아도 직접 입력으로 모든 암송 기능을 이용할 수 있습니다.

4. 제3자 제공

본 앱은 사용자의 어떠한 정보도 제3자에게 제공하지 않습니다.

5. 외부 서비스

본 앱은 광고, 분석 SDK, 소셜 로그인 등의 외부 서비스를 사용하지 않습니다.

6. 데이터 보관 및 삭제

모든 데이터는 사용자의 기기에만 저장되므로, 다음 방법으로 직접 삭제할 수 있습니다.

  • 앱 내 설정 메뉴에서 "데이터 초기화"
  • 운영체제의 앱 정보 → 저장공간 → 데이터 지우기
  • 앱을 삭제하면 모든 데이터가 함께 제거됩니다

7. 아동의 개인정보 보호

본 앱은 만 14세 미만 아동의 개인정보를 수집하지 않으며, 모든 기능이 개인정보 수집 없이 사용 가능합니다.

8. 보안

암송 기록·북마크·설정 등 앱이 저장하는 모든 데이터는 사용자 기기 내부에만 보관되며, 외부 네트워크로 전송되지 않습니다. 개발자가 운영하는 서버가 없으므로 서버 측 정보 유출 위험이 존재하지 않습니다. 예외적으로 음성 인식 기능을 사용할 때에 한해, 위 3-1에 기재된 대로 운영체제의 음성 인식 시스템과 통신이 발생할 수 있습니다.
