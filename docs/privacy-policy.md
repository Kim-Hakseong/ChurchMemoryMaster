「교회학교 암송 수첩」(이하 "본 앱")은 이용자의 개인정보를 수집하지 않습니다.
본 방침은 본 앱이 어떤 정보를 다루고 다루지 않는지를 투명하게 알리기 위해 작성되었습니다.

## 1. 수집하는 개인정보

**본 앱은 어떠한 개인정보도 수집하지 않습니다.**

- 회원가입, 로그인, 계정 생성 절차가 없습니다.
- 이름, 이메일, 전화번호, 생년월일 등 개인을 식별할 수 있는 정보를 요구하지 않습니다.
- 광고 식별자, 위치 정보, 연락처, 사용 기록을 수집하지 않습니다.
- 이용자의 정보를 외부 서버로 전송하지 않으며, 개발자를 포함한 누구도 이용자의 이용 내역을 열람할 수 없습니다.
- 분석 도구(애널리틱스), 광고 SDK, 크래시 수집 도구를 사용하지 않습니다.

## 2. 기기에 저장되는 정보

본 앱은 아래 정보를 **이용자의 기기 내부에만** 저장합니다. 외부로 전송되지 않습니다.

| 항목 | 내용 |
|---|---|
| 암송 진행 기록 | 암송 완료 여부, 획득 포인트, 연속 암송 일수, 뱃지 |
| 북마크 | 이용자가 저장한 말씀 구절 |
| 앱 설정 | 부서 선택(유치부·초등부·중고등부), 화면 테마, 글자 크기, 알림 요일·시간 |

이 정보들은 앱을 삭제하면 기기에서 함께 삭제됩니다.

## 3. 접근 권한

본 앱은 아래 권한을 요청할 수 있으며, 각 권한은 해당 기능을 사용할 때만 쓰입니다.
권한을 허용하지 않아도 해당 기능을 제외한 나머지 기능은 정상적으로 이용할 수 있습니다.

### 마이크 · 음성 인식 (선택)

"완전 암송" 연습에서 암송한 말씀을 음성으로 입력할 때 사용합니다.

- 본 앱은 음성을 **녹음하여 저장하지 않으며**, 개발자의 서버로 전송하지 않습니다.
- 음성을 텍스트로 변환하는 처리는 운영체제가 제공하는 음성 인식 기능을 이용합니다.
  이 과정에서 음성 데이터가 **Apple(iOS) 또는 Google(Android)의 음성 인식 시스템으로 전송되어 처리될 수 있습니다.**
  해당 처리는 각 사업자의 개인정보 처리방침을 따릅니다.
  - Apple: https://www.apple.com/legal/privacy/kr/
  - Google: https://policies.google.com/privacy
- 변환된 텍스트는 암송 정답을 확인하는 데에만 쓰이고, 확인 후 저장되지 않습니다.

### 알림 (선택)

이용자가 설정한 요일·시간에 암송 알림을 보내기 위해 사용합니다.
알림은 **기기 내부에서 생성되는 로컬 알림**이며, 외부 서버를 거치지 않습니다.

### 사진 (선택, Android)

암송 카드를 이미지로 저장할 때 사진 라이브러리에 접근합니다.
저장은 이용자가 저장 버튼을 눌렀을 때만 이루어지며, 앱이 기존 사진을 읽거나 외부로 전송하지 않습니다.

다만 위 3항에 기재된 대로, 음성 인식 기능을 사용할 경우 운영체제 제공 사업자(Apple·Google)의 음성 인식 시스템이 이용됩니다.
